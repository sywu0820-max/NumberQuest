# Number Quest product contract

Audience: approximately age 7, touch-first tablet use.

The experience is an adventure game whose mechanic happens to exercise arithmetic. It must avoid exam-like pressure.

## v0 scope
Eight sequential worlds cover 20-within addition/subtraction, 50-within mixed arithmetic, multiplication groups 1/2/5, 3/4/6, 7/8/9, 100-within mixed arithmetic, and a final mixed world.

A world is cleared after five correct answers. Correct answers award gems and XP. A cleared world unlocks the next world. Wrong answers receive encouraging retry feedback and never erase earned progress.

## Privacy
No login, analytics, ads, external API calls, or child data upload in the core product. State remains in browser local storage.

## First dogfood question
Does the child voluntarily start another world after completing one?
