# Number Quest Grade 2A — 十的核心玩具 v0 founder-review contract

## Gate and ancestry

This hidden microtoy branches directly from accepted PR #14 head `a891c71bc0733848d457c26c3e5e4e0e15563836`. It does not inherit or extend the frozen PR #19 child surface. Access is only through `ten-core.html?prototype=ten-core-v0`; ordinary Number Quest has no entry.

## One reversible relationship

The entire playable surface is ten identical loose balls beside one transparent frame with ten visible slots.

- Every ball has one stable ID and one persistent DOM node.
- A tap places a loose ball in the next empty slot.
- A drag places that same loose ball only when released over an empty visible slot.
- An outside drop leaves the mathematical state unchanged and settles the same ball back where it began.
- Every placed ball remains visible.
- Nine balls cannot close the frame or reveal a label.
- The tenth ball closes the outline around the same ten objects, then reveals `10` and `10 個一 = 1 個十`.
- Tapping the completed frame opens it, hides both labels, and moves the same ten DOM nodes back to their original tabletop layout.

There is no instruction paragraph on entry. After four idle seconds, one loose ball and the next empty slot pulse without acting, storing help, or changing state.

## Founder gate

Judge only whether the first action is discoverable, the same ten objects visibly become one grouped ten without changing quantity, opening is visibly reversible, and the result feels like a direct mathematical toy. Stop at this gate; do not add levels, missions, prompts, or another World.

### Under-60-second review path

1. Drag one loose ball into any empty slot; drop another outside the frame and confirm it returns unchanged.
2. Tap the remaining loose balls until the tenth settles; confirm all ten remain visible and only then reveal `10 個一 = 1 個十`.
3. Tap the completed frame; confirm the same ten balls return to the original loose layout and the relationship can be repeated immediately.
