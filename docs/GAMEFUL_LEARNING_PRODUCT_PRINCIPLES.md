# Gameful Learning Product Principles

Status: durable product-planning guidance for Number Quest and future child-learning products.

Sources synthesized:
- Yu-kai Chou, *Actionable Gamification: Beyond Points, Badges, and Leaderboards* / 《遊戲化實戰全書》
- Yu-kai Chou & Mark Diaz, *10,000 Hours of Play* / 《一萬小時的遊戲》

This is not a request to maximize engagement. It constrains how motivation design may be used in learning products.

## Prime directive

The product win state is not time-on-app, streak length, questions answered, DAU, points, badges, or collectibles.

The learning win state is:

> A child could not yet do something, becomes able to do it independently, can still retrieve it after time has passed, and can transfer the same mathematical relationship to a different surface context.

Engagement is useful only when it helps produce that outcome.

## Human-focused design, not PBL decoration

Design around why a child wants to act, not around attaching points / badges / leaderboards to worksheets.

- rewards follow meaningful progress; they do not substitute for it;
- a badge without a real challenge has little learning meaning;
- do not make low-value repetition attractive only by increasing external rewards;
- every game mechanic must name the learning behavior and human motivation it supports.

## Prefer empowering motivation for children

Strongly prefer:
- Development & Accomplishment;
- Empowerment of Creativity & Feedback;
- meaningful purpose used lightly and authentically;
- Ownership tied to genuine capability growth;
- Curiosity / Unpredictability in content and discovery;
- Relatedness without comparison pressure.

Keep Scarcity, Loss & Avoidance, and coercive mechanics low.

Do not use:
- streak-loss anxiety;
- expiring learning rights;
- lives that block learning after mistakes;
- overdue / debt framing for review work;
- red-deficit shame;
- manipulative scarcity;
- gambling-shaped randomized reward loops;
- child leaderboards or rank pressure as a default mechanism.

## Design the journey, not isolated mechanics

Evaluate Discovery → Onboarding → Scaffolding → mature experience.

For Number Quest:
- Discovery: curiosity should make the child want to begin.
- Onboarding: teach interaction and learning rules with early authentic success.
- Scaffolding: the daily core loop must remain satisfying over many sessions.
- Mature experience: mastery, transfer, retention, new combinations and ownership replace endless reward inflation.

## Creativity and agency

Answer selection should gradually evolve toward bounded learner agency.

Examples:
- allow a child to choose how to receive help after a miss;
- allow multiple valid strategies where mathematically appropriate;
- give feedback about the chosen strategy, not only correctness;
- reward independent recovery and discovery more than passive hint consumption.

Productive struggle remains non-negotiable:

Challenge → struggle → hint / strategy choice → discovery → mastery.

## Curiosity belongs in content, not addictive reward randomness

Use unpredictability through varied story worlds, semantic relationships, representations, bounded mission sequences, and discoveries in the mastery map.

Avoid using uncertainty primarily to make rewards compulsive.

## Ownership means “my growing capability”

Prefer skill-map regions lighting up after demonstrated mastery, worlds built by retained capabilities, meaningful collections, and light customization.

Avoid rewarding volume alone.

## 10K HP alignment model

Use the six-element alignment model carefully for children:

1. Game / Mission
2. Attributes / learner signals
3. Role / Identity
4. Skills / Craft
5. Allies / Network
6. Quests / Milestones

### Game / Mission
A session should feel like a meaningful mission, not “complete 20 exercises.”

### Attributes
Use observed learning state, preferences, confidence, representation strengths and struggle patterns as changing signals. Never turn them into fixed labels such as “a weak math child.”

### Role / Identity
Support constructive identity such as number explorer, builder or detective. Identity should emerge from actions and choices, not grade labels.

### Skills
Make real capability progression legible: acquisition → independent retrieval → transfer → retention.

### Allies
Parents, teachers, siblings and AI should enable the child to succeed independently. They should not replace thinking or become surveillance/ranking systems.

### Quests
Break a long learning journey into bounded missions with meaningful progress and feedback.

## Alignment beats any single mechanic

Mission → learner state → role/identity → skills → allies → quests → feedback → updated learner state.

A feature is suspect when it is locally engaging but conflicts with the larger learning mission.

## The journey itself must be rewarding

A child should experience worthwhile moments while still struggling:
- curiosity;
- choosing a method;
- seeing a relationship become clearer;
- recovering after a miss;
- recognizing something from a prior day;
- noticing that a once-hard skill now feels easy.

## Metrics hierarchy

When metrics conflict, prioritize:

1. learning correctness and safety;
2. independent mastery and retention;
3. transfer across contexts / representations;
4. learner autonomy and willingness to return;
5. healthy engagement;
6. cosmetic reward consumption.

Never optimize #5 or #6 at the expense of #1–#4.

## Feature review checklist

For every future gameful feature ask:
1. What learning behavior does this improve?
2. Which human motivation does it serve?
3. Is that motivation empowering or coercive?
4. Can the child game the reward without learning?
5. Does it preserve productive struggle?
6. Does it increase agency, competence, curiosity, relatedness, or meaningful ownership?
7. Does it create pressure, anxiety, comparison, or artificial scarcity?
8. Does it strengthen Game → Attributes → Role → Skills → Allies → Quests alignment?
9. Would we still want this feature if retention metrics were hidden from us?
10. How will we test that learning, not merely engagement, improved?

## Durable principle

> Build a game worth learning through, not a learning task wrapped in game rewards.

> The goal is not to make a child grind for 10,000 hours. The goal is to make meaningful growth feel enough like play that sustained practice becomes something the child is willing to choose.
