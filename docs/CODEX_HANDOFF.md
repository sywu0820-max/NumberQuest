# Codex handoff

Repository: sywu0820-max/NumberQuest

Read `AGENTS.md` before changing code. Treat `main` as shared product truth.

For each bounded task:
1. Inspect current repository state and relevant product contract.
2. Create a focused branch.
3. Implement only the accepted scope.
4. Validate math invariants and touch UX on iPad/Surface-sized viewports.
5. Commit with a descriptive message and open a PR.
6. In the PR body report WHAT changed, WHY, validation performed, known limitations, and exact areas requiring ChatGPT judgment.
7. Do not merge before review when the change affects learning rules, progression, rewards, or child-facing UX.

Priority product metric: after finishing a level, does the child voluntarily choose to play another level?
