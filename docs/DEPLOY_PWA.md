# Deploy Number Quest as a PWA

Recommended host: GitHub Pages over HTTPS.

Repository settings: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

Expected URL: `https://sywu0820-max.github.io/NumberQuest/`

iPad: open the URL in Safari → Share → Add to Home Screen → Add. Surface Pro: open the same URL in Edge and use Install app when offered.

After the first successful online load, the service worker caches the core app for offline play.
